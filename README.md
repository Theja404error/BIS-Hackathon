# BIS Standards Recommendation Engine

RAG-powered system that recommends Bureau of Indian Standards (BIS) for Indian MSE products in the Building Materials category (SP 21).

## Architecture

```
Product Description
       ↓
[Hybrid Retriever]  ← BM25 + dense embeddings (BAAI/bge-small-en-v1.5) fused via RRF
       ↓
  Top 10 candidates (whitelist)
       ↓
[LLM Re-ranker]     ← Llama 3.3 70B via Groq (low-temp, JSON-structured)
       ↓
[Whitelist Validator]  ← prevents hallucinated codes
       ↓
Top 3-5 BIS Standards + rationale
```

## Setup (5 minutes)

### 1. Install dependencies
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
```

### 2. Get a free Groq API key
1. Go to https://console.groq.com/keys
2. Sign in with Google → create API key
3. Copy `.env.example` to `.env` and paste your key:
```bash
cp .env.example .env
# edit .env and put your key in GROQ_API_KEY
```

### 3. Drop the BIS dataset PDFs into `data/raw_pdfs/`
The organizers provided SP 21 PDFs — put them all in `data/raw_pdfs/`.

### 4. Build the index (one-time, ~2-5 min)
```bash
python -m src.ingest        # parse PDFs → chunks
python -m src.retriever     # build BM25 + FAISS indices
```

### 5. Run it!

**Streamlit UI (for demo):**
```bash
streamlit run app.py
```

**Inference script (judges run this):**
```bash
python inference.py --input data/public_test_set.json --output data/results.json
```

**Evaluation:**
```bash
python eval_script.py  # uses the organizer-provided script
```

## Key Design Decisions (use these in your slide deck)

1. **Standard-aware chunking** — chunks are anchored to IS code boundaries, not fixed token windows. Prevents splitting a single standard's summary across chunks.

2. **Hybrid retrieval (BM25 + dense)** — fused via Reciprocal Rank Fusion. Catches both exact code lookups and paraphrased queries.

3. **Whitelist-constrained generation** — LLM can only pick from retrieved candidates. Eliminates hallucinated IS codes (= full marks on "No Hallucinations" metric).

4. **Low temperature (0.1)** — deterministic outputs; same query → same answer.

5. **Graceful degradation** — if LLM call fails, falls back to retrieval order. Pipeline never crashes the eval script.

## Troubleshooting

- **`No PDFs found`** → put SP 21 PDFs in `data/raw_pdfs/`
- **`GROQ_API_KEY not set`** → check your `.env`
- **Slow first query** → first call loads the embed model (~30s); subsequent queries are ~1-2s.
- **Want to use Gemini instead?** → set `LLM_PROVIDER=gemini` in `.env` and add `GEMINI_API_KEY`.
